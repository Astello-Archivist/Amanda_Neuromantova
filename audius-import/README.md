# Сопоставление с Audius

Проверка: 13 октября 2026 года.

## Все ссылки ведут на один профиль

Все **166 треков** каталога найдены в профиле [Astello](https://audius.co/astello). В нём доступны **217 публичных загрузок**, включая повторы.

По просьбе владельца каталога заменены **102 ссылки** на соответствующие записи Astello. Остальные 64 ссылки уже вели на этот профиль. Несопоставленных строк — **0**.

## Проверка

Названия, исходные имена файлов и длительности проверены. Для заменяемых ссылок дополнительно совпали идентификаторы исходных файлов Audius с предыдущими загрузками. При повторных загрузках выбирается один доступный вариант с тем же исходником; уже выбранные ссылки Astello сохраняются.

Фактическая длительность пяти исходников ранее проверена полным декодированием и исправлена в каталоге. Все ссылки, включая «Вар — Прокачка», отображаются обычным образом.
