## Правила сопоставления

Сравниваются полные названия с исполнителем и версией, исходные имена загруженных файлов и длительность. Пробелы, пунктуация, регистр и ударения не влияют на сравнение. Номера версий сохраняются. Допуск по длительности — 1,1 секунды: Audius возвращает целые секунды, исходная длительность включает доли секунды и служебные аудиокадры. При нескольких подходящих версиях ссылка автоматически не добавляется. Ранее заполненные ссылки сохраняются.
