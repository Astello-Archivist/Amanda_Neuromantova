# Ch-D Music Collection

Черновой каталог. tracks.csv — таблица для Excel/Google Sheets (UTF-8, разделитель точка с запятой). tracks.json — данные для будущего каталога на GitHub.

Исполнители и названия автоматически разделены по имени файла и требуют проверки. Тексты, жанры и сущности пока не анализировались. Пустые ссылки предназначены для Google Drive и YouTube. Несколько тегов в ячейке разделяются знаком |.

characters — персонажи; items — ключевые предметы; named_animals — именные животные. notes — пояснения и спорные расшифровки.

SHA-256 обнаруживает точные дубликаты; группы записаны в duplicates.json. Разные версии песен сохраняются отдельными строками. Аудиофайлы не изменены и не включены в каталог.

Встроенные метаданные извлечены средствами Windows в metadata.json. Поля metadata_* в таблице содержат значения из файлов; они могут отличаться от названий файлов и не являются результатом анализа аудио. duration_seconds — длительность в секундах; bitrate_kbps — битрейт. SHA-256 — контрольная сумма содержимого файла, а не музыкальные метаданные.

Встроенные изображения извлечены без изменения аудиофайлов в covers/. cover_path — относительный путь к основной обложке (предпочтительно лицевая сторона); cover_count — количество изображений; cover_paths — все пути через |. Пустой путь означает, что встроенное изображение не найдено. covers.json содержит список изображений и ошибки извлечения. Это встроенные картинки аудиофайлов, не подтверждённые обложки видеоклипов. Для повторного извлечения: python music-catalog/extract_covers.py из корня проекта.

## Каталог в браузере

Откройте index.html двойным щелчком. Установка и сервер не нужны. Есть поиск, фильтры, карточки/список, обложки и подробности треков. Ссылки Drive/YouTube отображаются после их заполнения. Аудио в репозиторий не входит.

После изменения tracks.csv запустите из папки проекта:

```powershell
.\.venv\Scripts\python.exe music-catalog\build_catalog.py
```

Скрипт обновляет tracks.json и catalog-data.js. Таблица CSV является источником данных; изменения, сделанные только в JSON, будут заменены при сборке.

Для GitHub загрузите содержимое этой папки в репозиторий Amanda_Neuromantova, сохраняя covers/. Приватность репозитория не заменяет настройки доступа отдельного веб-хостинга.
